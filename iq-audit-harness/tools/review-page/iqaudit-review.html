  1. Natural? Would someone who writes this way plausibly send this message? Mark it if it reads like a caricature, a textbook, or machine translation.
  2. Same meaning? Same facts, numbers and reasoning steps as the English line. Nothing added, dropped, or made smarter or dumber.
  3. Fix it. If anything is off, write a better version in the note. Your rewrite is what will go into the test.
